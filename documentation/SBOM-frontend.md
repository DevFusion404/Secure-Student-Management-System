## jQuery Migrate — Transition Notes

`jquery-migrate-3.5.2.min.js` is loaded **immediately after** `jquery.min.js` in `footer.php`.
It re-introduces APIs removed in jQuery 3 that older vendored plug-ins may depend on:

| Removed API | Migration path |
|---|---|
| `$(element).load(fn)` | Use `$(window).on('load', fn)` |
| `$(element).unload(fn)` | Use `$(window).on('beforeunload', fn)` |
| `$(element).error(fn)` | Use `.on('error', fn)` |
| `$(element).size()` | Use `.length` |
| `$(element).andSelf()` | Use `.addBack()` |
| `$.browser` | Use feature detection instead |

Open the browser console after deploying — Migrate logs every deprecated call with a migration hint.
Remove Migrate once all warnings have been resolved in the plug-in code.

## Retire.js Integration

Run the following after **any** dependency change to check for known vulnerabilities:

```bash
# Install once
npm install -g retire

# Scan the vendor directory
retire --path assets/vendors --outputformat text
```

A clean run should produce **no findings** for jQuery after the 3.7.1 upgrade.
